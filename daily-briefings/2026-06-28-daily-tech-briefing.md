## 1. Programming & Software Development

### AI coding agents are becoming part of everyday development workflows
AI coding tools are increasingly being used for multi-step development work such as debugging, refactoring, generating tests, preparing documentation, and implementing small features.

**Why this matters to Nathan:**
As a developer working with Java, PHP, JavaScript, Android, Flutter, WordPress, and backend systems, the biggest advantage is not only asking AI to generate code, but building repeatable workflows for tasks like:

- Reviewing pull requests
- Generating unit tests
- Refactoring legacy PHP/Java code
- Producing API documentation
- Creating database migration plans
- Debugging Android/Flutter build issues

**Practical action:**
Create reusable prompts or Codex tasks for your common project workflows, especially for WordPress maintenance, Flutter MVVM features, Android Java fixes, and PHP/MySQL systems.

---

### Specification-driven development is becoming more important
Modern AI-assisted development works better when the project has clear requirements, architecture notes, API contracts, database schema documentation, and acceptance criteria.

**Why this matters to Nathan:**
For larger systems such as AgriTrack, inventory systems, SACCO/finance tools, and client WordPress projects, AI tools will produce better code when the project structure is well documented.

**Practical action:**
For each serious project, maintain:

- `README.md`
- `docs/architecture.md`
- `docs/database-schema.md`
- `docs/api-spec.md`
- `docs/tasks.md`

This will help you, collaborators, and AI coding agents work faster with fewer mistakes.

---

### Security review is still necessary for AI-generated code
AI-generated code can speed up development, but it still requires human review, especially around authentication, authorization, input validation, file uploads, and secret management.

**Why this matters to Nathan:**
Your work involves mobile apps, web apps, payment integrations, user accounts, Firebase, WordPress, PHP/MySQL, and cloud hosting. These areas can expose sensitive data if security is not handled carefully.

**Practical action:**
Before deploying AI-assisted code, review:

- API keys and secrets
- SQL injection risks
- Firebase/Firestore rules
- File upload validation
- Role-based access control
- Password reset flows
- Payment callback verification
